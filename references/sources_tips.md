# Sources -- AI Tips & How-To Content

## What makes a good tip
- Directly usable by a finance, treasury, or port ops professional the same day
- Specific enough to act on (not "use AI to be more productive")
- Tied to a tool or platform the audience likely has access to
- Ideally demonstrates something new that was not possible 6 months ago
- Aim for 3-5 tip candidates per issue so the user can choose the best fit

---

## Source categories (search all of these each run)

### 1. YouTube -- practical demos and walkthroughs
Search via `site:youtube.com [topic]` in WebSearch (direct WebFetch to youtube.com returns 403).

Priority channels (run at least one search per channel per run):
- Anthropic: `site:youtube.com anthropic claude finance agents tutorial [year]`
- SAP / Oracle / Workday: `site:youtube.com SAP OR Oracle OR Workday AI finance agents demo [year]`
- Microsoft Mechanics / M365: `site:youtube.com microsoft copilot finance reconciliation tutorial [year]`
- Oracle Modern Finance: `site:youtube.com oracle modern finance AI agent demo [year]`
- Anaplan: `site:youtube.com anaplan AI planning agent demo [year]`
- AICPA & CIMA: `site:youtube.com AICPA CIMA AI finance tutorial [year]`

Additional catch-all searches (run at least 2 per scout):
- `site:youtube.com AI treasury "cash flow" forecast tutorial [year]`
- `site:youtube.com "AI agent" CFO accounts payable month-end close [year]`

Pick videos where the title is clearly instructional ("How to...", "Demo:", "Walkthrough",
"Step-by-step"). Avoid opinion pieces or news summaries.

### 2. Vendor webinars (recorded, on-demand)
These are often more detailed than YouTube clips and cover governance/rollout questions.

- https://www.anthropic.com/webinars  (Claude finance and enterprise webinars)
- https://www.kognitos.com/webinars  (Claude + MCP finance workflow demos)
- https://www.cfoconnect.eu/resources/event-recaps  (CFO Connect AI event recaps)
- Oracle EPM webinars, Anaplan CPX sessions
- https://www.blackline.com/resources/  (BlackLine BeyondTheBlack)
- https://www.highradius.com/resources/  (HighRadius webinars)

### 3. Written step-by-step guides
- https://finstoryai.substack.com  (Finance + AI practical install guides)
- https://buildingprofit.substack.com  (Automate finance workflows with Claude)
- https://reruption.com/en/knowledge/how-to-ai/finance/  (Finance AI how-to library)

### 4. Editorial / thought leadership with actionable takeaways
Only use if the article contains a specific technique or checklist a finance team can act on.

- https://hbr.org/topic/subject/artificial-intelligence
- https://sloanreview.mit.edu/topic/artificial-intelligence/
- https://www.cfo.com/technology/

## Tip format in draft.md

Add at the end of the draft, after all news sections:

```
---

## Tip of the Week

[One-line description -- e.g. "Use Claude to draft board variance commentary in 10 minutes"]

[2-3 sentences: what to do, how to do it step by step, what outcome to expect.
Keep it actionable -- a finance team member should be able to try it the same day.]

Source: [URL]
```

## Scout instruction for Phase 1

Run all 8 YouTube search patterns above. Also check at least 2 webinar sources and
2 written guide sources. Target 3-5 tip candidates total. Record each as `tips_NNN`
with category `tips`. Score on relevance/novelty/materiality like any other item;
tips scoring 24+ are strong candidates.
